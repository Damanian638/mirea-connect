# Ручное подключение

Сначала выполните установку из [основной инструкции](../README.md). Этот способ нужен, если автоматическое подключение не получилось.

## Получите параметры своего компьютера

1. Откройте PowerShell (Windows) или Терминал (macOS/Linux).
2. Выполните:

```bash
mirea-connect prompt --json
```

3. Сохраните результат. В нём есть поля `name`, `command`, `args` и `transport`.

Значение `command` — полный путь к установленному Python. Используйте именно путь из вашего результата. Копировать путь с чужого компьютера не нужно.

Если команда не найдена, откройте новое окно терминала. Можно использовать полный путь, напечатанный установщиком: в PowerShell поставьте перед путём `&`, заключите путь в кавычки и добавьте `prompt --json`.

## ChatGPT / Codex

В приложении откройте настройки MCP и добавьте локальный сервер:

| Поле | Значение |
|---|---|
| Имя | `mirea` |
| Транспорт | `stdio` — запуск локальной команды |
| Команда | Значение `command` из вашего результата |
| Аргументы | Три отдельных аргумента: `-m`, `mirea_connect`, `local` |
| Рабочая папка и переменные окружения | Оставьте пустыми |

Сохраните, включите сервер и создайте новый локальный чат. Если добавляете аргументы одной строкой, используйте `-m mirea_connect local`; если редактор принимает JSON-массив, используйте `["-m", "mirea_connect", "local"]`.

Эти настройки относятся к локальному агенту приложения, не к сайту ChatGPT. [Справка OpenAI](https://learn.chatgpt.com/docs/developer-settings).

## Claude Desktop

Проще повторить автоматическое подключение: откройте Claude, затем выполните `mirea-connect install` и выберите Claude Desktop.

При ручной настройке откройте конфигурацию локальных MCP-серверов Claude и добавьте запись `mirea` в объект `mcpServers`. Сохраните существующие серверы. Формат записи:

```json
{
  "mcpServers": {
    "mirea": {
      "command": "ЗАМЕНИТЕ НА command ИЗ ВАШЕГО РЕЗУЛЬТАТА",
      "args": ["-m", "mirea_connect", "local"]
    }
  }
}
```

В JSON обратные косые черты пути Windows должны быть удвоены: `C:\\Users\\…`. Полностью перезапустите Claude. [Официальная справка](https://support.claude.com/en/articles/10949351-getting-started-with-local-mcp-servers-on-claude-desktop).

Если установщик сообщил, что файл настроек содержит ошибку JSON, он этот файл не менял. Исправьте ошибку (часто это лишняя запятая перед `}`) или добавьте запись `mirea` вручную, как показано выше, затем повторите установку.

## Google Antigravity (`agy` / Antigravity IDE)

### Через команду CLI (быстрый способ)

В терминале выполните:

```powershell
agy mcp add mirea -- "ЗАМЕНИТЕ НА command ИЗ ВАШЕГО РЕЗУЛЬТАТА" -m mirea_connect local
```

Флаг `--` перед аргументами обязателен, чтобы `-m` не воспринимался как флаг самой команды `agy`.

### Через конфигурационный файл вручную

Файл настроек MCP Antigravity находится по пути:
* **Windows**: `%USERPROFILE%\.gemini\config\mcp_config.json`
* **macOS / Linux**: `~/.gemini/config/mcp_config.json`

Добавьте секцию `mirea` в объект `mcpServers`:

```json
{
  "mcpServers": {
    "mirea": {
      "command": "ЗАМЕНИТЕ НА command ИЗ ВАШЕГО РЕЗУЛЬТАТА",
      "args": [
        "-m",
        "mirea_connect",
        "local"
      ],
      "disabled": false
    }
  }
}
```

После сохранения перезапустите `agy` или откройте новый чат в Antigravity. Набор инструментов `mirea` станет доступен автоматически.

> **Совет:** Чтобы агент работал автономно без запроса подтверждения на каждый шаг, запустите CLI с флагом `agy --mode auto` или настройте `"agentMode": "auto"` через команду `/config`.
