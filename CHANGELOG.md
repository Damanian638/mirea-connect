# Изменения

## Unreleased

### Проверка ответов на задания и оценивание в СДО (Moodle)

- **Просмотр сданных работ (`sdo_assign_submissions`).** Таблица ответов студентов на задание (`assign`): даты сдачи, статус, прикреплённые файлы и текущие оценки. Поддерживается быстрый поиск по фамилии, имени, email и фильтр по учебной группе.
- **Чтение файлов отчётов (`sdo_read_submission_file`).** Извлечение текста ответов студентов из форматов DOCX, PDF, TXT, C/CPP, ASM, Python и др. (до 25 МБ) для проверки прямо в диалоге.
- **Поддержка DOCX в материалах курса (`sdo_read_file`).** Добавлено извлечение текста из документов `.docx` в элементах курса (ранее поддерживались только PDF/TXT/CSV/MD).
- **Скачивание файлов ответов (`sdo_download_submission_file`).** Сохранение прикреплённых студентами файлов на локальный диск компьютера.
- **Выставление оценок и отзывов (`sdo_grade_submission`).** Отправка формы оценивания задания в СДО: балл за работу и текстовая рецензия/комментарий преподавателя.

### Исправлено

- **Расписание преподавателя.** При нескольких совпадениях («Иванов») коннектор больше не выбирает первого попавшегося человека, а возвращает список вариантов. Преподавателя можно указать фамилией с инициалами («Иванов И. И.»). Пустой запрос больше не выдаёт расписание случайной группы.
- **Свободные аудитории.** Латинские буквы, похожие на русские (`B-78`, `A-9`), распознаются: раньше такой корпус давал 0 свободных аудиторий. Неверное время (`25:00`, `10:60`) даёт понятную ошибку вместо падения с трейсом. Если по корпусу ничего не найдено, возвращается список корпусов со свободными аудиториями.
- **Даты.** `date_from` / `date` принимают только `ГГГГ-ММ-ДД`; дата со временем или часовым поясом раньше молча сдвигала начало дня. Отрицательное `days` отклоняется.
- **Сетевые ошибки и изменения API** дают понятное сообщение в MCP и CLI без трейса и без адресов SSO.
- **Установщик.** Настройки Claude Desktop / Cursor в UTF-8 с BOM (так сохраняет Блокнот Windows) или с ошибкой JSON больше не затираются: раньше пропадали все остальные MCP-серверы. При ошибке подключения `mirea-connect install` завершается с ненулевым кодом, и скрипты установки не печатают «Готово».
- **install.ps1** проверяет код возврата uv и коннектора (`$ErrorActionPreference` этого не делает), правильно читает путь с кириллицей в имени пользователя, подсказывает закрыть клиенты, если файлы заняты, и при ошибке не закрывает окно PowerShell.
- **install.sh** сообщает понятную причину при ошибке загрузки uv, установки и подключения.
- Повторная установка обновляет пакет (`--reinstall`), а не берёт старую копию из кеша uv.
- **Локальный вход.** Вывод браузера (`xdg-open`) больше не попадает в stdout — канал протокола MCP. Таймер старой страницы входа не закрывает новую. Если порт страницы занят, `login` возвращает ошибку, а не завершает весь MCP-процесс.
- **Журнал** удалённого и локального режимов маскирует значения параметров адресов: `session_code`, одноразовые `code` OAuth, `req` и т. п. больше не пишутся в лог.
- **Удалённый вход.** Число попыток входа ограничено и для каждой учётной записи: подмена `X-Forwarded-For` больше не позволяет обойти лимит по IP.
- **Docker.** Каталог `/data` принадлежит пользователю контейнера: раньше `docker run` без смонтированного тома падал с `PermissionError`. Для недоступного на запись каталога выводится понятная подсказка.

### Изменено

- `pymirea` закреплена на коммите `b4af5fc` вместо ветки `main`: установка воспроизводима, а изменения библиотеки не ломают вход без проверки.

### Управление курсами СДО

- Добавлены MCP-инструменты структуры курса, чтения материалов и текста PDF/TXT/CSV/MD-вложений.
- Через HTTP-формы Moodle создаются скрытые страницы, текстовые блоки, ссылки, задания, папки и тесты; можно обновлять тексты и отдельно менять видимость.
- Добавлены создание/редактирование разделов и добавление вопросов с одним правильным ответом в скрытый тест.
- Проверяются принадлежность элементов курсу, адреса обработчиков и фактическое сохранение. Повтор одинакового создания элемента возвращает существующий; сетевые ошибки записи не запускают автоматический повтор.
- Добавлены проверки сериализации форм, прав, скрытой видимости, ограничений загрузки и регистрации MCP-инструментов.

### Установка Windows

- Установщик проверяет коды завершения uv и коннектора, не продолжает подключение и не пишет «Готово» после ошибки.
- Перед обновлением проверяются процессы в окружении MIREA Connect, чтобы не заменять занятую установку.
- Перед подключением проверяется запуск установленного коннектора; в README добавлено восстановление после `os error 5` и `ModuleNotFoundError`.

### Авторизация

- Вход Пульса начинается через `/api/auth/login` с поддержкой обязательного PAR.
- Обрабатываются скрытые OAuth-формы `form_post` после GET и POST.
- OAuth-код обменивает сервер Пульса; коннектор не пытается погасить его раньше callback.
- Поддерживаются `Pulse.Auth.Cookie`, прежняя `.AspNetCore.Cookies` и составные cookies.
- Авторизация подтверждается ответом `UserService/GetMeInfo`, а не одним наличием cookie.
- При ошибке без действующего OTP-шага локальная страница возвращает форму входа.
