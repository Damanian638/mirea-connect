# MIREA Connect

**Расписание МИРЭА и поиск свободных аудиторий в вашем ИИ-ассистенте.**

## Шаг 1. Выберите и установите приложение

Выберите **один** вариант и хотя бы один раз откройте приложение после установки:

| Вариант | Что установить | Оплата |
|---|---|---|
| **ChatGPT / Codex** | [Приложение OpenAI для компьютера](https://learn.chatgpt.com/docs/app). Войдите через свой аккаунт ChatGPT. | Доступ и лимиты зависят от вашего тарифа. |
| **Claude** | [Claude Desktop](https://claude.com/download). Установите и войдите в аккаунт Claude. | Действуют тариф и лимиты Claude. |
| **DeepSeek Harness** | На [официальной странице](https://www.deepseek.com/en/harness/) нажмите **Download Desktop**, выберите Windows или macOS и установите приложение. | Само приложение бесплатное. Использование официальных моделей оплачивается отдельно. |

**Про бесплатный вариант.** MIREA Connect бесплатен. DeepSeek Harness тоже можно установить бесплатно, но это не означает бесплатные ответы ИИ: по [условиям DeepSeek](https://www.deepseek.com/en/harness/terms-of-use/) для официальных моделей нужен баланс Open Platform. Бесплатная работа возможна с подключённой моделью, которая сама предоставляется бесплатно; её настройка зависит от поставщика. Бесплатный безлимит здесь не обещается.

Для ChatGPT ниже описано подключение **в приложении на компьютере с локальным агентом Codex**. Если у вас открыт только сайт ChatGPT в браузере, см. [пояснение про веб-версию](#если-вы-пользуетесь-chatgpt-в-браузере).

## Шаг 2. Установите MIREA Connect

### Windows

1. Откройте меню **Пуск**.
2. Напишите **PowerShell** и откройте **Windows PowerShell**. Запускать от администратора не нужно.
3. Скопируйте всю команду ниже, вставьте в окно PowerShell и нажмите **Enter**:

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://raw.githubusercontent.com/Damanian638/mirea-connect/main/install.ps1 | iex"
```

4. Дождитесь окончания загрузки. Установщик сам скачает Python и необходимые компоненты. Не закрывайте окно, пока идёт установка.
5. Когда появится вопрос **«Куда подключить MIREA Connect?»**, перейдите к шагу 3 ниже.

### macOS или Linux

Откройте приложение **Терминал**, вставьте команду и нажмите **Enter**:

```bash
curl -LsSf https://raw.githubusercontent.com/Damanian638/mirea-connect/main/install.sh | sh
```

Дождитесь меню выбора приложения. Python и необходимые компоненты установятся автоматически.

## Шаг 3. Подключите выбранное приложение

В меню установщика введите **номер нужного пункта** и нажмите **Enter**. Номера зависят от того, какие программы найдены на вашем компьютере: ориентируйтесь на название.

### ChatGPT / Codex

1. Выберите в меню установщика пункт **Codex**. Так он называется в установщике, в том числе для приложения с общей конфигурацией ChatGPT / Codex.
2. Дождитесь сообщения **«Подключено: Codex»**.
3. Полностью закройте приложение и откройте снова.
4. Создайте новый локальный чат. В настройках **MCP** найдите сервер **mirea** и убедитесь, что он включён.
5. Перейдите к шагу 4.

Если пункта Codex нет: откройте приложение, завершите первоначальную настройку и снова запустите установку из шага 2. Если он всё ещё не появился, используйте [ручное подключение](docs/manual-connection.md).

Подключение использует общие настройки локального агента — это описано в [официальной документации OpenAI](https://learn.chatgpt.com/docs/developer-settings).

### Claude Desktop

1. Выберите в меню установщика пункт **Claude Desktop**.
2. Дождитесь сообщения **«Подключено: Claude Desktop»**.
3. Полностью завершите Claude, в том числе через значок возле часов, если приложение осталось работать в фоне. Затем откройте его снова.
4. Создайте новый чат. В меню инструментов возле поля сообщения проверьте, что доступен **mirea**.
5. Перейдите к шагу 4.

Если Claude Desktop нет в списке: запустите Claude, войдите в аккаунт, закройте приложение и повторите шаг 2. Эта установка предназначена для программы на компьютере. [Справка Claude о локальных подключениях](https://support.claude.com/en/articles/10949351-getting-started-with-local-mcp-servers-on-claude-desktop).

### DeepSeek Harness

1. Откройте установленный **DeepSeek Harness** и настройте вход / модель по подсказкам приложения. Обычный сайт DeepSeek эту установку не заменяет.
2. В меню установщика MIREA Connect выберите **«Другой агент или харнесс — показать промпт…»**. DeepSeek автоматически в список клиентов не добавляется.
3. Установщик покажет текст, начинающийся с **«Подключи к себе MCP-сервер MIREA Connect»**. Обычно он сразу копируется в буфер обмена. Если копирование не сработало, выделите и скопируйте весь текст между разделительными линиями.
4. Вставьте этот текст в **новый чат DeepSeek Harness** и отправьте.
5. Разрешите приложению добавить локальное подключение `mirea`, если оно запросит подтверждение. В тексте уже указаны параметры именно вашего компьютера.
6. Дождитесь проверки подключения. Если приложение попросит перезапуск, закройте его и откройте снова. Затем перейдите к шагу 4.

Промпт — просьба агенту выполнить настройку, а не гарантия автоматического подключения. Если агент не смог добавить сервер, выполните [ручное подключение по полям](docs/manual-connection.md#deepseek-harness). Harness поддерживает локальные MCP-серверы через настройки; [официальная документация](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/mcp/mcp-manager/README.md).

## Шаг 4. Проверьте, что всё работает

Отправьте в чат выбранного приложения:

> Используй MIREA Connect. Найди преподавателя по фамилии и покажи его расписание на ближайший понедельник. Сначала спроси у меня фамилию.

Ассистент должен обратиться к инструментам **mirea** и получить расписание. **Для публичного расписания вход в аккаунт МИРЭА не нужен.**

Теперь можно спросить, например:

> Найди свободные аудитории на проспекте Вернадского, 78, в понедельник с 10:40 до 12:10. Укажи точную дату и выдай списком.

> Покажи лабораторные и практические преподавателя Иванова И. И. на следующую неделю.

Свободная по расписанию аудитория может быть закрыта или иметь ограничения доступа. Время занятий — московское.

## Шаг 5. Войдите в МИРЭА, если нужны личные данные

Для проверки расписания этот шаг можно пропустить.

1. Напишите ассистенту: **«Войди в МИРЭА через MIREA Connect»**.
2. Откройте предложенную страницу входа в браузере на этом же компьютере.
3. Введите логин и пароль **на странице входа**. Если придёт код, введите его там же.
4. Дождитесь сообщения **«Готово»** и вернитесь в чат.

Пароль и код в чат присылать не нужно. Для СДО может потребоваться отдельный вход. Если университет завершит сессию, ассистент предложит войти снова; закрытие чата само по себе сессию не удаляет.

Коннектор получает данные в пределах прав вашей учётной записи. Выставление оценок и изменение курсов сейчас не реализованы.

## Если что-то не получилось

| Что произошло | Что сделать |
|---|---|
| Нужного приложения нет в меню | Установите его, откройте и войдите в аккаунт, затем повторите шаг 2. Для DeepSeek выберите «Другой агент или харнесс». |
| Ассистент отвечает, что не видит MIREA Connect | Полностью перезапустите приложение, создайте новый чат и проверьте, включён ли сервер `mirea` в настройках MCP. |
| Команда `mirea-connect` не найдена | Закройте PowerShell и откройте снова. Если не помогло, используйте полный путь, который установщик вывел после слов «Готово. Команда:». |
| Не удалось войти или подтвердить код | Попросите ассистента начать вход заново. Вводите последний полученный код в новой форме. |
| Требуется обновление | Повторите команду из шага 2, затем перезапустите приложение. |

Если ошибка осталась, [сообщите о ней](https://github.com/Damanian638/mirea-connect/issues): напишите, какое приложение и Windows/macOS/Linux вы используете, и приложите текст ошибки. Пароли, коды и данные сессии не прикладывайте.

### Если вы пользуетесь ChatGPT в браузере

Сайт ChatGPT не читает локальную конфигурацию из этой инструкции. Для веб-версии нужен отдельный удалённый MCP-сервер или Secure MCP Tunnel. Это более сложный способ: [инструкция OpenAI](https://developers.openai.com/api/docs/guides/custom-mcp-server), [справка по удалённому серверу MIREA Connect](docs/technical.md#удалённый-сервер). Для начала используйте приложение на компьютере.
