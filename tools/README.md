## 📊 Быстрый запуск: Генератор сетки расписания и дебаггер (Web UI)

В репозиторий включён визуальный веб-интерфейс для кафедр, преподавателей и студентов, позволяющий формировать официальную сетку расписания в формате Excel (`.xlsx`) и детально анализировать данные расписания:

- **Выгрузка в Excel по официальной форме**: пары 1–7, дни недели, недели I / II, разделение типов занятий, преподаватели, группы, точное соответствие стилей и заливок.
- **Любые объекты**: сетка для произвольного списка аудиторий (например, кафедры), отдельного преподавателя или студенческой группы.
- **Интерактивный предпросмотр**: просмотр таблицы прямо в браузере до скачивания файла.
- **Умная фильтрация семестров**: отсекает устаревшие занятия прошлых семестров из базы.
- **Фильтр прошедших занятий**: автоопределение текущей недели семестра и скрытие уже завершённых дисциплин/циклов с сохранением будущих пар.
- **Вкладка «Debug (для разработчиков)»**: интерактивный инспектор сырых записей API расписания с фильтрами по аудитории, паре, неделе и дню.

### Запуск в один клик:

Скрипты запуска автоматически создают изолированное окружение, проверяют и при необходимости докачивают нужные библиотеки (`pymirea`, `openpyxl`), запускают сервер и сразу открывают браузер:

- **Windows**: дважды кликните по файлу **`start.bat`** в папке проекта.
- **macOS / Linux**: запустите в терминале:
  ```bash
  ./start.sh
  ```
- **Универсально через Python**:
  ```bash
  python start.py
  ```

*Все исходные файлы веб-приложения и консольные скрипты находятся в папке [`tools/`](tools/).*

## Решение проблем

| Проблема | Решение |
|---|---|
| Ошибка CORS в браузере при открытии HTML | Запустите сервер через `start.bat` (Windows) или `./start.sh` (Linux/macOS) — запросы будут проксироваться без ограничений. |
| Батник `start.bat` вылетает | Убедитесь, что установлен Python 3.11+ и при установке была включена опция «Add Python to PATH». Обновлённый `start.bat` теперь не закрывает окно при ошибках. |
| Инструменты не видны в чате | Полностью закройте приложение (включая трей возле часов) и запустите снова. |
| Найдено несколько преподавателей | Уточните запрос: укажите фамилию с инициалами («Иванов И. И.») или полное ФИО. |
